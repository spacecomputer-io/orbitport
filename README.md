This repository contains the Orbitport project by SpaceComputer.

## Overview

Orbitport is a gateway to orbital services, providing a secure and reliable way to access services such as `cTRNG` (cosmic True Random Number Generator) or `spaceTEE`, served by multiple providers & satellites to ensure high availability and reliability.

Orbitport is designed to be easy to use and integrate with multiple types of web3 and web2 systems, making it an ideal choice for developers and organizations looking to leverage the power of space-based services.
